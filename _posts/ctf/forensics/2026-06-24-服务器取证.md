#### Mysql

###### Linux重置root密码

1.在 /etc/my.cnf 的 [mysqld] 下加入 skip-grant-tables

2.重启 MySQL 服务（systemctl restart mysqld）

3.直接输入 mysql 进入数据库，执行 SQL 命令修改 root 密码，如果用户 'root'@'%' 已经存在，CREATE USER 会报错。此时应改用 ALTER USER 修改密码。

```
-- 1. Flush privileges to pull the user tables into memory
FLUSH PRIVILEGES;

-- 2. Set your actual strong new password (replace 'YourNewStrongPass8.0!'),MySQL 8.0
CREATE USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'YourNewStrongPass8.0!';

-- 2. Update the password for the root user (replace 'YourNewPassword123!' with your desired password),MySQL 5.7
ALTER USER 'root'@'%' IDENTIFIED BY 'YourNewPassword123!';

-- 3. If ALTER USER gives an error, clear the password first by making it empty
CREATE USER 'root'@'%' IDENTIFIED BY '';

-- 3.5 grant privileges if needed.
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;

-- 4. Save changes and exit
FLUSH PRIVILEGES;
EXIT;
```

4.必须把 /etc/my.cnf 中的这一行删掉或注释掉（改回 #skip-grant-tables）

5.再次重启 MySQL 服务，恢复正常的密码验证模式。

#### [kali进入救援模式](https://it.sohu.com/a/829391267_121965800)

1. 出现GRUB菜单时快速按下 `Esc`/`Shift` 键

2. 选择内核行页面，按 `e` 进入编辑模式

3. 修改启动参数，找到`linux/linux16/linuxfi`开头的行，添加`init=/bin/bash  #直接进入bash`

4. 启动救援，按 `Ctrl+X` 或 `F10` 生效

5. 挂载根目录读写：

   ```
   mount -o remount,rw / 
   chroot /sysroot
   ```
